# Assets

Every model, texture, sound, and icon in this repository is original and generated by scripts in `tools/assetgen/` (see its README for exact commands). No sampled audio, scanned textures, or third-party models are used.

| Asset | Source | Regenerate |
|---|---|---|
| Discs, tile, frame, base (`assets/models/*.obj`) | Procedural Blender 5 pipeline (lathed profiles, reeded rims, crown emblem) | `blender -b --factory-startup --python tools/assetgen/build_models.py` |
| Board, room, and piece textures (`assets/textures/*`) | Procedural numpy generator: tileable albedo, normal (OpenGL +Y), and roughness | `python3 tools/assetgen/gen_textures.py` |
| Environment light (`assets/textures/env/club.hdr`) | Procedural HDR panorama of the club room | same script |
| Sound effects and music (`assets/audio/*.ogg`) | Modal synthesis of disc-on-wood contacts, additive vibraphone/handbell/electric piano, a swing ballad in F; encoded with libvorbis | `python3 tools/assetgen/gen_audio.py` |
| UI icons | Original SVGs in `scripts/ui/icon_library.gd` | — |
| App icon | Original SVG (`icon.svg`, `assets/icons/`) | — |
| Fonts | Inter and Inter Display, SIL Open Font License 1.1 | — |

Puzzle positions and the opening book were composed for this project; the openings themselves are standard theory.
